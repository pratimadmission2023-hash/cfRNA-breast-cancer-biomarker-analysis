# cfRNA-breast-cancer-biomarker-analysis

## Project Overview

This project demonstrates a bioinformatics workflow for analyzing synthetic cell-free RNA (cfRNA) expression data in the context of breast cancer biomarker research.
The project is designed as a research and bioinformatics portfolio project and uses a synthetic dataset. No patient-level or confidential clinical data are included.

## Research Background

Cell-free RNA (cfRNA) circulating in blood plasma is being investigated as a minimally invasive source of molecular biomarkers.
This project focuses on the computational analysis of RNA and miRNA expression profiles relevant to breast cancer biomarker research.

## Aim

To develop and demonstrate a reproducible bioinformatics workflow for exploring synthetic cfRNA expression data and investigating candidate breast cancer biomarkers.

## Candidate Biomarkers

The analysis will include selected RNA and miRNA features, including:

- miR451a
- miR486
- miR21
- miR155
- miR205
- SCGB2A2
- AGR2
- TFF1
