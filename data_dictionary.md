# Synthetic cfRNA Dataset — Data Dictionary

This dataset is entirely synthetic and was generated for educational and portfolio purposes. It does not contain patient-level data or information from identifiable individuals.

| Column | Description | Type |
|---|---|---|
| Sample_ID | Synthetic sample identifier | Categorical |
| Tumour_Grade | Simulated tumour grade (1–3) | Ordinal |
| Tumour_Size_mm | Simulated tumour size in millimetres | Continuous |
| Lymph_Node_Status | Simulated lymph-node status | Categorical |
| HER2 | Simulated HER2 status | Categorical |
| PR | Simulated progesterone receptor status | Categorical |
| LVSI | Simulated lymphovascular space invasion status | Categorical |
| Survival_Months | Simulated follow-up time in months | Continuous |
| Survival_Status | Simulated censoring/event status | Categorical |
| miR451a | Simulated miRNA expression/count | Numeric |
| miR486 | Simulated miRNA expression/count | Numeric |
| miR21 | Simulated miRNA expression/count | Numeric |
| miR155 | Simulated miRNA expression/count | Numeric |
| miR205 | Simulated miRNA expression/count | Numeric |

| TFF1 | Simulated protein-coding RNA expression/count | Numeric |
| MALAT1 | Simulated lncRNA expression/count | Numeric |

## Important note

The numerical values are artificial and should not be interpreted as clinical measurements, biological evidence, or results from the University of Aberdeen MSc project.
